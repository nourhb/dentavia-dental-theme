== Description ==

Dentavia is a fresh, modern Full Site Editing theme crafted for dental clinics. Clean white and teal design with soft rounded corners, a prominent Book Appointment call-to-action, treatments grid, smile gallery, team profiles, pricing tables, opening hours and FAQ patterns — everything a modern dental practice needs to welcome new patients online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and style variations. Translation-ready and accessibility-conscious.

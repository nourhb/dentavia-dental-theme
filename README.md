# Dentavia — Dental Clinic WordPress Theme

A fresh, modern **Full Site Editing (FSE)** block theme crafted for dental clinics. Clean white + teal design with soft rounded corners, a prominent **Book Appointment** call-to-action, and everything a modern practice needs to welcome new patients online.

## Features

- 🦷 **Multipage templates** — Home, Services, Team, About, Contact, plus Page, Wide Page, Single, Archive, Search and 404
- 📅 **Booking-focused** — hero booking card, appointment form layout, opening-hours block, emergency CTA
- 😁 **Smile gallery** — before/after style transformations showcase
- 👩‍⚕️ **Team profiles** — dentist cards with photos, roles and bios
- 💰 **Transparent pricing** — three-tier pricing table pattern
- ❓ **FAQ accordion** — anxiety-friendly patient questions
- 🌊 **"Deep Sea" style variation** — darker teal alternative
- ✨ Scroll reveals, animated counters, back-to-top button (respects reduced motion)
- 🌍 Translation-ready (`dentavia` text domain)
- ♿ Accessibility-conscious markup

## Design

- **Colors:** Teal `#0d9488`, Deep Teal `#0f766e`, Pine `#134e4a`, Mint `#99f6e4`, Mist `#f0fdfa`
- **Fonts:** Inter (body) + Playfair Display (headings), bundled as WOFF2 (OFL licensed)

## Photos

All 15 photos are real, freely-licensed (Pexels) dental photography bundled in `assets/images/` — dentists treating patients, modern operatories, bright smiles and team portraits. No placeholders.

## Requirements

- WordPress 6.4+
- PHP 7.4+
